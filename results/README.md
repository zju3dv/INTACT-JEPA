# Evaluation Results

`20260804/official_direct` and `20260804/clear_v051_moderate` contain audited
results for the corrected previous-action checkpoints. Each suite covers 72
checkpoints, three evaluation seeds per checkpoint, and 100 episodes per
evaluation: 216 evaluations and 21,600 episodes.

Aggregate reports and all seed-level SR rows are included. Raw videos,
datasets, checkpoints, and runtime caches are intentionally excluded.

The selected repository default is summarized in
[`20260804/CANONICAL_FOUR_SLOT_P77_CN.md`](20260804/CANONICAL_FOUR_SLOT_P77_CN.md):
four-slot actor inputs with the 7/7 local/goal window protocol.
