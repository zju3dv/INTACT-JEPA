- Controller：Direct，零搜索，solver batch size `1`。

## 结论

1. CLEAR v0.5.1 下，五槽 7/5 的 Macro 最高，为 `84.61±0.99%`；因此论文原定 7/5 协议仍是 CLEAR 指标下的最佳配置，不需要因 Official sweep 的微小优势改成 6/6。
2. Reacher 是 Macro 下降的决定因素。六种配置在 Official 下为 `95.89–97.89%`，在 CLEAR Moderate 下为 `47.78–52.22%`。这不是重新训练后的性能退化，而是同一 checkpoint 在修正成功语义后的重评结果。
3. PushT 在 CLEAR 下达到 `86.00–89.33%`，全部高于对应 Official 结果，说明去除 trivial case 并未让该任务机械性变难；改变的是评估样本与任务判定的有效性。
4. Cube 仍为 `99.78–100.00%`，对这批强模型基本饱和。TwoRoom 为 `96.11–98.89%`，整体很高，但四槽 6/6 的训练 seed 方差达到 `5.59pp`。
5. CLEAR 下五槽 7/5 相对四槽 7/5 提高 `+1.17pp` Macro，主要来自 Reacher `+4.00pp` 与 TwoRoom `+1.89pp`；PushT 上四槽反而高 `1.11pp`。因此五槽优势仍应表述为总体经验优势，不是四任务逐项支配。
